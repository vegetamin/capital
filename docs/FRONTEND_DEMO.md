## 资产构成口径

| 一级项目 | 二级项目 | 数据来源 |
| --- | --- | --- |
| 灵活资金 | 现金、活期、现金管理账户名称 | `cash`、`bank`、`money` |
| 定期存款 | 定期账户名称 | `fixed` |
| 投资资产 | 证券资金账户、证券代码与持仓名称 | `investment`、`holdings` |
| 应收债权 | 债权账户名称 | `receivable` |
| 其他资产 | 其他资产账户名称 | `other` |

负债不属于资产构成，负余额无法表达为饼图扇区；二者均不进入图表。标记为待核的账户及其关联持仓继续遵守现有审计排除规则。

## 交互

- 首页显示一级项目名称、占比和金额。
- 点击一级扇区或右侧项目行进入二级构成。
- 二级占比以当前一级项目为分母。
- 点击“全部资产”返回一级视图。
- 键盘可聚焦扇区并用 Enter 或空格进入明细。

## 验证

运行 `npm test`。新增测试覆盖一级分组、负债排除、待核账户排除、投资持仓合并及二级占比。
